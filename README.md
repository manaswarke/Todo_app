# To-Do Application

A task management utility built in Python to help users organize, track, and complete daily objectives. The project repository is structured to include both the uncompressed development directory and a deployment archive.

## 📁 Repository Structure

* **`todo_app/`** – Main development directory containing the application's source modules, workflow logic, and layout assets.
* **`todo_app.zip`** – A compressed archive containing the complete project folder structure for quick distribution, transfer, or local backup extraction.

## 🚀 Key Features

* **Task Management:** Seamlessly create, display, mark as complete, or purge items from your active list.
* **Persistent Storage:** Keeps task lists saved locally between script runs so data isn't lost when closing the app.
* **Streamlined UI:** Organized with an accessible layout optimized for direct, everyday task tracking.

## 💻 Setup & Execution

1. Confirm that Python is installed and configured in your system environment path.
2. Download or clone this workspace repository locally.
3. If using the archive, extract the files from `todo_app.zip`.
4. Open your terminal or console terminal inside the extracted directory.
5. Run the entry-point script (e.g., `main.py` or the primary driver file inside the folder):
   ```bash
   python main.py
